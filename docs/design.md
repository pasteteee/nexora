# Описание дизайна (v0.1)

## Принципы
1. **Холст — это весь экран.** Никаких полей и рамок вокруг страницы: рабочая область
   занимает 100 % окна, интерфейс плавает поверх неё.
2. **Минимум текста.** Действия — иконки. Подпись появляется только подсказкой по наведению.
3. **Кнопки сгруппированы.** Связанные действия живут в одной «пилюле» (`<Group>`), группы
   разделены тонким сепаратором. Постоянно видны только основные инструменты (п. 4.1.5 ТЗ),
   остальное — ПКМ, «⋯» и горячие клавиши.
4. **Тени вместо рамок.** Поверхности отделяются мягкой тенью `--shadow-1/2`.
5. **Движение 150–300 мс**, `cubic-bezier(.2,.8,.2,1)`; при `prefers-reduced-motion` анимации гаснут.

## Токены
См. `app/globals.css`: цвета (`--bg`, `--surface`, `--ink`, `--accent`…), 6 цветов стикеров,
радиусы 8/12/18, две тени, три длительности. Светлая и тёмная тема.

## Компоненты (`components/ui`)
`IconButton` · `Group`/`Sep` · `Button` (primary/ghost/danger) · `Field` · `Dialog` ·
`Menu` (контекстное и «⋯», скрывает недоступные роли пункты) · `Toast` (с действием «Отменить») ·
`Skeleton` · `Spinner`.
