# Описание дизайна (v0.2)

## Направление
Тетрадь на столе. Страница — это лист, который пишут **сверху вниз**, как конспект в Word или Notion.
Холста с масштабом больше нет: вместо свободного размещения блоки перетаскивают за ручку на полях
выше, ниже или в колонку рядом.

- **Бумага и графит.** Тёплые нейтральные цвета (оттенок 85° в OKLCH), без чистого белого и чёрного.
- **Зелёные чернила** — единственный акцент: главная кнопка, ссылки, галочки, линия места вставки.
- **Красная линия полей** — фирменная деталь. Слева от неё живут ручки `+` и `⋮⋮`.
- **Маркеры** — пять мягких цветов фона блока, как текстовыделитель.
- **Шрифт** Onest (кириллица, текст и интерфейс), JetBrains Mono — код и TeX.

## Принципы
1. Писать можно сразу: клик под последним блоком, Enter, «/» — без панелей инструментов.
2. Подписи словами там, где действие не очевидно; иконки — только с подсказкой.
3. Одна высота отступа у блоков, радиусы 4 / 6 / 10 px, тень только у всплывающих меню.
4. Движение 120–200 мс, только в ответ на действие; при `prefers-reduced-motion` анимации гаснут.

## Редактор
| Действие | Как |
|---|---|
| Новый блок / разрезать | Enter (Shift+Enter — перенос строки) |
| Тип блока | «/» и поиск, или Markdown: `# `, `## `, `### `, `- `, `1. `, `[] `, `> `, `! `, `$$ `, ```` ``` ````, `---` |
| Перетащить | ручка `⋮⋮` слева: выше/ниже, к левому или правому краю блока — колонка рядом (до 4) |
| Ширина колонок | потянуть промежуток между колонками |
| Меню блока | клик по `⋮⋮`: превратить в, цвет, дублировать, выше/ниже, удалить |
| Выделить блок | Esc; затем ↑/↓ (Shift — несколько), Delete, Ctrl+D, Ctrl+Shift+↑/↓ |
| Отступ | Tab / Shift+Tab |
| История | Ctrl+Z / Ctrl+Shift+Z — набор в одном блоке считается одним шагом |
| Вставка | многострочный текст становится несколькими блоками |

## Хранение
Блок — строка в `elements` (схема БД не менялась): `y` — порядок (дробный, вставка не сдвигает соседей),
`x` — номер колонки, `width` — доля ширины колонки, `content_json` — `{ kind, text, checked, indent, row }`,
`style_json` — `{ tint }`. Старые заметки с холста открываются как абзацы.

## Токены
См. `app/globals.css`: `--bg`, `--surface`, `--ink…`, `--accent`, `--margin-rule`, `--tint-*`, `--cover-*`,
радиусы `--radius-s/m/l`, тени `--shadow-pop/drag`. Светлая и тёмная тема.
