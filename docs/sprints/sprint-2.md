## Что получилось
- **Два режима данных.** С ключами Supabase работает настоящая база с RLS, без ключей — демо-режим
  в браузере (`localStorage`) с теми же правилами: роли, одинаковый ответ для чужого и несуществующего,
  корзина 30 дней. Письма в демо-режиме показываются прямо на экране.
- **Вход.** Регистрация с подтверждением e-mail, повторная отправка письма, восстановление пароля
  по одноразовой ссылке, возврат на исходную страницу после входа.
- **Тетради.** Плитки во всю ширину без полей, создание в один клик (сразу с первой страницей),
  переименование на месте, корзина с отменой.
- **Страницы.** API: создание, переименование, порядок, дублирование (одной транзакцией в БД), корзина.
  Тетрадь открывается на первой странице; полноценный холст — спринт 3.

## Проверка (QA)
- Unit и интеграционные тесты: `npm test` — 16 тестов (валидация, вход только после подтверждения,
  одноразовые ссылки, изоляция чужих тетрадей, корзина и очистка через 30 дней, дублирование страницы
  с переназначением связей и групп, порядок страниц).
- Ручной прогон в демо-режиме: регистрация → письмо → «Мои тетради» → создание → страница → корзина.
- Критерии ТЗ п. 6.2, закрываемые спринтом: 1, 2, 17, 33, 34, 35; 28 частично.
