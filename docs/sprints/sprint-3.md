## Что получилось
- **Холст на весь экран без полей.** Масштаб 10–400 % колесом/жестом вокруг курсора, прокрутка,
  «рука» на пробеле и средней кнопке, «Показать всё». Четыре фона (чистый, клетка, точки, линейка)
  и шаг 16/24/32/48 — сохраняются в странице. Позиция камеры — в браузере пользователя.
- **Границы мира** ±5 000, растут шагом 5 000 до ±500 000; за пределом — «Достигнута граница страницы».
- **Выделение:** клик, Shift, рамка; группа выделяется целиком. Перетаскивание нескольких объектов,
  8 маркеров изменения размера (Shift — с пропорциями). Двойной клик по пустому месту — новая заметка.
- **Автосохранение** без кнопки: геометрия раз в 200 мс, текст через 1 с, при ошибке — «Не сохранено»
  с повтором, изменения не теряются.
- **История** на 100 шагов, буфер обмена, дублирование, удаление со связями, сдвиг стрелками.

## Горячие клавиши
| Клавиши | Действие |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | отменить / повторить |
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D | копировать / вырезать / вставить / дублировать |
| Delete, Backspace | удалить |
| Ctrl+A, Esc | выделить всё, снять выделение |
| Стрелки (Shift) | сдвиг на 1 (10) |
| + / − / 0 | масштаб, 100 % |
| Shift+1 / Shift+2 | показать всё / выделение |
| Пробел + мышь | перемещение камеры |
