# База данных

Миграции: `supabase/migrations/`, применяются по порядку.

```bash
supabase link --project-ref <ref>
supabase db push
```

| Файл | Что делает |
|---|---|
| `0001_init.sql` | таблицы Приложения 1 (+ `deleted_at`, `position`, `group_id`), индексы п. 4.3.1.3, pgvector, триггеры `updated_at`, авто-членство владельца, отключение публикаций при удалении тетради |
| `0002_rls.sql` | RLS по матрице прав Приложения 2: участники читают, owner/editor пишут, owner управляет участниками и приглашениями |

Модель объекта холста — одна таблица `elements`: геометрия в колонках, содержимое и стиль в JSONB
(п. 4.3.1.1), поэтому новый тип объекта не требует новой таблицы.
