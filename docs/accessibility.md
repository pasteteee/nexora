# Доступность и движение (спринт 7, карточка #41)

## Как проверить

```bash
npm run build
npx next start -p 3100              # без переменных Supabase, демо-режим
npm run a11y                        # axe-core, правила WCAG 2.2 A/AA; --all печатает и мелкие замечания
```

Скрипт проверяет лендинг, вход, «Мои тетради», профиль, редактор (светлая и тёмная схема,
все 7 тем тетради) и публичную страницу на компьютере и телефоне 390×844. В редакторе он ещё
открывает с клавиатуры меню виджета, галерею виджетов, меню «/», редактор формулы и диалог
«Поделиться». Код выхода 1, если есть нарушения уровня serious или critical.

Итог на 08.11.2026: нарушений нет на всех 16 экранах и в 5 открытых состояниях.

## Что исправлено

- **Контраст AA.** Приглушённый текст (`--ink-3`: подсказки, счётчики, «Корзина страниц»)
  был 2,5–3,0:1. Теперь не меньше 4,5:1 на фоне, бумаге и подсветке во всех темах.
  Акцентный текст на светлой подложке и в тёмной схеме подтянут до 4,5:1. Текст на акцентной
  кнопке берётся из нового токена `--accent-ink`: в тёмной схеме он тёмный, белый на светлом
  акценте давал 2,97:1. В теме «Точки» акцент стал темнее, в «Крафте» темнее цвета «готово»
  и «внимание».
- **Меню для экранного диктора.** У списков есть имя («Блоки и виджеты», название виджета).
  В меню «/» фокус остаётся в строке, и диктор читает выделенный пункт через
  `aria-activedescendant`. В меню виджета фокус переходит на пункт, а после выбора или Escape
  возвращается на ручку.
- **Перемещение с клавиатуры.** Подсказка ручки объясняет, что стрелки двигают виджет, а Enter
  открывает меню. Каждое перемещение объявляется («Текст: ниже»). Пока меню открыто, стрелки
  управляют меню и больше не двигают виджет под ним. Ручка видна при любом фокусе.
- **Меньше движения.** При `prefers-reduced-motion` плавная прокрутка к заголовку из оглавления,
  к новому виджету и к источнику в «Материалах» стала мгновенной. CSS-переходы уже были
  отключены этим правилом.

## Что уже было в порядке

- Переходы 150–300 мс по токенам «Описания дизайна», лоадеры с `role="status"`,
