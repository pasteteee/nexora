# ADR-002. Языковая модель и модель эмбеддингов

Статус: предложено (спринт 1), фиксируется на стадии «Технический проект». Карточка Trello #3.

## Требования ТЗ

- единый серверный адаптер для генерации и эмбеддингов (п. 4.1.1.1), ключи только на сервере (п. 4.1.4.1);
- ответы на языке запроса, RU и EN (п. 4.3.2);
- до 5 фрагментов по косинусному сходству, порог 0,3 (п. 4.2.7);
- таймаут 60 с, стриминг, отмена (п. 4.2.8).

## Сравнение

| Критерий | Anthropic Claude (генерация) | OpenAI (генерация + эмбеддинги) | Локальная модель |
|---|---|---|---|
| Качество RU/EN | высокое | высокое | среднее |
| Стриминг, отмена | есть | есть | зависит от сервера |
| Эмбеддинги | нет своих, берём отдельного провайдера | `text-embedding-3-small`, 1536 изм. | e5 / bge, 768–1024 |
| Учебный бюджет | платно | платно | бесплатно, но нужен сервер |

## Предложение

- Генерация: Grok (адаптер `xai`, Responses API) по выбору владельца 30.10.2026. Сохранены адаптеры `anthropic` и `openai`; выбор задаётся `AI_PROVIDER`.
- Эмбеддинги: отдельный провайдер через тот же интерфейс; размерность вектора фиксируется в
  миграции `source_chunks.embedding`. При смене модели — полная переиндексация (п. 4.2.6).
- Интерфейс `AiProvider` (`lib/ai/provider.ts`) не зависит от поставщика; UI вызывает только
  серверные маршруты `/api/ai/*`.
