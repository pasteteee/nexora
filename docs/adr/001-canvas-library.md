# ADR-001. Библиотека визуального холста

Статус: принято (спринт 1). Карточка Trello #2.

## Варианты

| Вариант | Лицензия | Плюсы | Минусы |
|---|---|---|---|
| tldraw | собственная, для продакшна нужен ключ/водяной знак | готовый редактор | лицензия не подходит учебному проекту без согласования; своя модель данных |
| Konva / react-konva | MIT | быстрый canvas, трансформеры | текст и формулы (KaTeX) рендерятся не в DOM, редактирование текста и a11y сложнее |
| Собственный DOM + SVG слой | — | объекты — обычные DOM-узлы: текст, KaTeX, изображения, выделение, a11y «бесплатно»; модель объектов полностью наша | всё взаимодействие (pan/zoom, drag, resize) пишем сами |

## Решение

Собственная реализация: мировой слой — один `div` с `transform: translate() scale()`,
объекты — абсолютно позиционированные DOM-узлы, соединители — SVG поверх.

Причины:
- п. 4.3.3.1 ТЗ требует независимости слоя отображения от модели хранения — у нас модель
  `CanvasElement` одна, рендер её только читает;
- 9 типов объектов (в т.ч. формула и текст) естественно живут в DOM;
- 100 объектов (критерий №22) — нагрузка, при которой DOM с одним трансформом держит 60 fps;
  при росте до сотен объектов добавим виртуализацию по видимой области.

## Проверка

Прототип: 100 объектов, pan/zoom колесом — без пропуска кадров в Chrome DevTools Performance.
