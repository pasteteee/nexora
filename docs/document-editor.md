# Документный редактор тетради

Редактор страницы работает как Markdown-блокнот. Текст находится в обычном потоке,
страница прокручивается вниз. Pan, zoom, поворот листа и маркеры изменения размера
не используются. Панели страниц и материалов/ИИ занимают отдельные колонки.

- На пустой странице можно сразу писать.
- Enter создаёт следующий блок, Shift+Enter переносит строку внутри блока.
- Backspace в начале абзаца объединяет его с предыдущим текстовым блоком.
- За ручку слева блок можно перенести. В меню ручки доступны перемещение вверх/вниз,
  добавление текста и удаление. Меню доступно с клавиатуры.
- Markdown отображается после выхода из редактирования, клик возвращает к исходнику.
- Изображения и материалы добавляются в поток, ответы ИИ становятся отдельными блоками.

Существующие элементы сохраняются в тех же таблицах. Порядок документа хранится в
`content_json.documentOrder`. Старые страницы упорядочиваются по прежним координатам;
сама геометрия остаётся в данных для совместимости и не управляет новым интерфейсом.
Дополнительная миграция БД или переменная окружения для этого изменения не нужна.

Перед сменой страницы редактор дожидается автосохранения. При ошибке сохранения
переход через интерфейс блокируется с сообщением о повторе. Если загрузка файла
закончилась после перехода, ссылка добавляется на исходную страницу.

Проверки: 94 автоматических теста, 14 проверок окружения, TypeScript, ESLint,
production build и сканирование публичных файлов. В браузере проверены ввод с первого
символа, Enter/Shift+Enter, объединение абзацев, отмена разделения, перетаскивание и
сохранение порядка после смены страницы.
