# Тест-план Nexora (первая очередь)

Ответственный: QA (Антон Редько). Карточка Trello #8.

## Уровни
| Уровень | Инструмент | Когда |
|---|---|---|
| Unit | Vitest (`npm test`) | каждый push, CI |
| Типы и линтер | `tsc`, ESLint | каждый push, CI |
| E2E | Playwright | перед закрытием ветки спринта |
| Ручная проверка | чек-лист карточки | перед закрытием ветки спринта |

## Процесс закрытия спринта
1. Разработчики закрывают карточки спринта, все коммиты в `sprint/N-…`.
2. QA прогоняет чек-лист своей карточки проверки и критерии ТЗ, перечисленные в ней.
3. Дефекты → комментарий в карточке задачи (блокирующий / существенный / косметический).
4. Нет блокирующих → PR `sprint/N → main`, QA одобряет и мержит; ветка закрывается.
